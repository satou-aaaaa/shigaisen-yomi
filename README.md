# 紫外線よみ（shigaisen-yomi）

UVインデックス（紫外線の強さの数）を見て、その段階（弱い・中程度・強い・非常に強い・極端に強い）を当てる1日5問の学習ゲーム。正解したら「その日の対策の目安は？」も選ぶ。紫外線のしくみ（時間・季節・地面の反射・雲・日陰・標高・日焼け止め）の問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/shigaisen-yomi/>

- 中身は環境省「紫外線環境保健マニュアル2020」（<https://www.env.go.jp/content/900410650.pdf>）に書いてあることだけです。段階の区分は WHO「Global solar UV index: a practical guide」（<https://www.who.int/publications/i/item/9241590076>）によります。
- 数字は目安で、場所・天気・時間で変わります。
- このゲームは医療の助言や、公式の情報の代わりではありません。その日の紫外線の情報は気象庁で確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
